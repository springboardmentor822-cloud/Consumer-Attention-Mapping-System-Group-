# AI Consumer Attention Mapping System

## Datasets Used

### COCO Dataset

Purpose:
- Person Detection

Status:
- Already used through the pretrained YOLOv8 model (yolov8n.pt).

---

### Retail Store Video

Purpose:
- Simulates the live CCTV feed of a retail store.

Status:
- Used as the input video for OpenCV and YOLO detection.

---

### SKU-110K

Purpose:
- Detect products placed on store shelves.

Status:
- Reserved for future enhancement.

---

### Retail Checkout Dataset

Purpose:
- Detect customer-product interactions and checkout activities.

Status:
- Reserved for future enhancement.
