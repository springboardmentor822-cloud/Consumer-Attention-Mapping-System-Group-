# Operational User Manual & Executive Operations Guide
**Platform**: AI-Powered Consumer Attention Intelligence Platform  
**Target Roles**: Store Managers, Retail Analysts, Marketing Managers, Administrators

---

## 1. System Access & Authentication

### Login Procedure
1. Launch browser and navigate to `http://localhost:3000`.
2. Select desired executive role profile or enter employee credentials:
   - **Store Manager**: `manager@retail.com` / `password123`
   - **Retail Analyst**: `analyst@retail.com` / `password123`
   - **Marketing Manager**: `marketing@retail.com` / `password123`
   - **Administrator**: `admin@retail.com` / `password123`
3. Click **Authenticate Platform Login** to open the role-tailored dashboard console.

## 2. Executive Role Workflow Operations

### Store Manager Workflow
- **Traffic Monitoring**: View total store footfall, active shoppers currently in aisles, and average dwell time.
- **Shelf Performance Indicators**: Inspect top performing shelves by view count, pickup count, and purchase conversion rate.
- **Live RTSP Surveillance**: Click any camera card to enter full-screen dedicated video stream analysis mode with planogram spatial overlays.
- **Alert Management**: Monitor real-time notifications for traffic congestion, shelf stock drops, and camera frame drops.

### Retail Analyst Workflow
- **Attention Heatmap Engine**: Navigate to **Heatmaps** to toggle spatial Gaussian KDE layers (`TRAFFIC`, `ZONE_DENSITY`, `GAZE_FOCUS`, `SHELF_HOTSPOT`).
- **Shopper Journey Flows**: Analyze Sankey path diagrams tracking shopper transition probabilities between entrance, aisles, and checkouts.
- **Shopper Segmentation**: Monitor shopper breakdown across Explorers, Quick Buyers, Comparison Shoppers, Impulse Buyers, and Brand Loyal customers.
- **Homography Calibration**: Click **Homography Calibration** to adjust coordinate transformation matrices for computer vision overlay accuracy.

### Marketing Manager Workflow
- **Campaign Performance**: Track sales uplift generated by active marketing promotions.
- **Visibility Radar Analysis**: Compare brand SKU performance across attention duration, interaction count, pickups, and final conversion.
- **Attractiveness Score Engine**: Inspect weighted attractiveness scores calculated using the formula:
  $$S = w_A \cdot A_{\text{norm}} + w_I \cdot I_{\text{norm}} + w_P \cdot P_{\text{norm}} + w_C \cdot C_{\text{norm}} + w_R \cdot R_{\text{norm}}$$

### Administrator Workflow
- **User & Role Access Assignment**: Add, edit, or remove employee accounts. Click **Purge Unauthorized Accounts** to clean unauthorized logins.
- **System Telemetry & Resource Monitoring**: Track CPU, Memory, GPU acceleration, API response latency (ms), and server uptime.
- **Security Audit Logs**: Inspect chronological login audit trails and endpoint execution records.

## 3. Operational Report Exports

1. Navigate to **Reports** in sidebar navigation.
2. Select desired report type: **Daily**, **Weekly**, **Monthly**, or **Custom**.
3. For custom reports, set **Start Date**, **End Date**, and **Filter Zone**.
4. Click **Download CSV** or **Print PDF Report** to generate verified documents.
