# Milestone 1: Week 1 and Week 2

## Scope

This milestone initializes the Consumer Attention Mapping System and delivers the core enterprise application shell.

## Included

- Project repository structure
- FastAPI backend setup
- PostgreSQL schema
- JWT authentication
- Password hashing
- Role-based access control
- React dashboard shell
- Admin pages for users, stores, shelves, products, cameras, profile, and settings
- CRUD APIs for stores, shelves, products, and cameras
- Docker-ready development environment

## Excluded

- YOLO
- Computer vision
- Consumer detection
- Shopper tracking
- Heatmaps
- Attention analysis
- Product attractiveness scoring
- Recommendation engine
- AI model integration
