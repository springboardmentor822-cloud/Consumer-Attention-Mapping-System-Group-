# Consumer Attention Mapping System

Milestone 1 project for Week 1 and Week 2: project initialization, design process, authentication, core dashboard setup, and CRUD management modules.

This milestone intentionally does not include computer vision, YOLO, shopper tracking, heatmaps, attention analysis, product attractiveness, recommendations, or AI models.

## Stack

- Frontend: React, Vite, Tailwind CSS, React Router, Axios, React Hook Form, React Icons
- Backend: FastAPI, SQLAlchemy, Pydantic, JWT, Passlib
- Database: PostgreSQL
- Development: Docker ready
